# Video (LTX-2.5) server requirements — self-contained list for the dedicated
# Lambda video instance's venv (built by backend/scripts/lambda/setup-lambda-video.ts
# on the kiki-video-<region> filesystem). The video venv is SEPARATE from the
# image venv: different diffusion stack (ltx-pipelines vs diffusers), different
# filesystem, dedicated GPU.
#
# Torch + torchvision + torchaudio are installed by the setup script
# (torch==2.9.1 cu128, same pin as the image path so behavior is comparable),
# not listed here. ltx-core declares `torch~=2.7`, which 2.9.1 satisfies.

# ─── LTX-2.5 via Lightricks' official packages ──────────────────────────────
# Lightricks doesn't publish to PyPI. Install from the LTX-2 monorepo, pinned
# to a specific SHA so model loading doesn't break on upstream main churn.
# Both packages must be present — ltx-pipelines depends on ltx-core.
# Pin a95ab856 (2026-08-26) = first main snapshot with the LTX-2.5 split
# checkpoint layout (ModelPaths.from_split), the Gemma 4 text encoder, the
# ancestral stage-1 sampler, and the DFR pipeline. Bumping this pin past
# an ltx-core minor is a model-servers change that needs a re-populate
# (setup-lambda-video.ts) — the serving venv lives on the NFS filesystem.
# License: LTX-2.x Community License Agreement (NOT Apache-2.0). Verify before
# any commercial deployment.
ltx-core @ git+https://github.com/Lightricks/LTX-2.git@a95ab856bf29407b6b066ede0abe1846050db56c#subdirectory=packages/ltx-core
ltx-pipelines @ git+https://github.com/Lightricks/LTX-2.git@a95ab856bf29407b6b066ede0abe1846050db56c#subdirectory=packages/ltx-pipelines
